pmrf.Param

pmrf.Param: TypeAlias = parax.variables.AbstractVariable | jaxtyping.Inexact[jaxlib._jax.Array, '...']

The canonical type hint for a parameter in a model. Parameters should be created using factories in pmrf.parameters, most of which are re-exported at root (e.g. pmrf.Value(), pmrf.Fixed(), pmrf.Bounded()).
