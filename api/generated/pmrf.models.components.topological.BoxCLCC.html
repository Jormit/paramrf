BoxCLCC

class pmrf.models.components.topological.BoxCLCC(C1: Any, L: Any, C2: Any, C3: Any, *, z0: complex = 50 + 0j, name: str | None = None, metadata: Any = None)

Bases: Model

A 4-port model of a Box-network with a Capacitor-Inductor-Capacitor-Capacitor topology.

This model consists of a shunt capacitor (C1), a series inductor (L), and a second shunt capacitor (C2), and a bridging capacitor (C3).

The parameter four_port determines whether all four ports are exposed or not.

Parameters:

  • C1 (Param) – First shunt capacitor.

  • L (Param) – Series inductor.

  • C2 (Param) – Second shunt capacitor.

  • C3 (Param) – Bridging capacitor.
